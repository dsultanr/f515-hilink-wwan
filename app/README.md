# F515 HiLink WWAN — приложение

Отдельное приложение «на полке», реализующее `~/f515/MODEM_ADB_GUIDE.md` в виде кнопки:
поднимает USB-модем (ZTE MF833R, `eth1`) как WAN и чинит DNS фантомной TBOX-сети, чтобы
Android и приложения реально считали интернет доступным. Без WireGuard, без демона —
один прогон скрипта по кнопке, идемпотентно.

Пакет `su.dsr.f515hilinkwwan`, отдельный от `netkeeper` (`su.dsr.keeper`) и от
`f515-huawei-wwan` (`su.dsr.f515wwan`) — независимый проект, можно ставить/не
ставить/удалять вне зависимости от них.

## UI

Три кнопки:
- **Проверка** — прогоняет `modem-up.sh --check`: то же самое, что и обычный запуск, но в
  режиме "только посмотреть" — ничего на устройстве не меняет, только печатает, что сделал
  бы.
- **Включить** — разворачивает `modem-up.sh` на устройство и запускает его по-настоящему,
  лог прогона сразу выводится на экран. Идемпотентно — жать можно сколько угодно раз.
- **Интернетометр** — открывает `https://internet.yandex.ru` системным обработчиком
  (`ACTION_VIEW`), чтобы визуально проверить, что интернет действительно есть.

Ничего не запускается автоматически: ни на BOOT_COMPLETED, ни при открытии приложения —
только по нажатию кнопки.

## Root

adbd на этой прошивке уже работает от root (`persist.adb.tcp.port=5555`,
`/data/misc/adb/adb_keys` пуст → принимает **любой** ключ) — `AdbClient.java` (минимальный
ADB-протокол: CNXN → AUTH RSA/SHA1 → OPEN `shell:`) коннектится на `127.0.0.1:5555` и сразу
получает root-шелл.

**`assets/adbkey`/`adbkey.pub` в этом репозитории — одноразовая заглушка**, сгенерированная
отдельно для публикации (не тот ключ, что используется локально). Раз adbd принимает любой
ключ, self-adb с ним всё равно работает на этой конкретной прошивке — но если ставите на
голову, ключ которой ключи всё-таки проверяет, сгенерируйте свой:
```bash
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -pkeyopt rsa_keygen_pubexp:65537 -out assets/adbkey
python3 mkadbpub.py assets/adbkey "you@host" > assets/adbkey.pub   # см. netkeeper/mkadbpub.py
```
**Никогда не коммитьте сюда свой реальный `~/.android/adbkey`** — это приватный ключ, если
голова(-ы), которым вы доверяете, проверяют ключи по списку, он даёт им root-доступ.

## Сборка

```bash
./build.sh          # -> F515HilinkWwanApp.apk
```
Тот же SDK, что у netkeeper (`/home/dsultanr/android-sdk`), тот же pipeline без gradle:
aapt2 → javac → d8 → zipalign → apksigner (своя `keystore.jks`, создаётся при первой сборке).

## Установка

Не устанавливалось на устройство (по аналогии с netkeeper — решение ставить или нет
принимает пользователь). `F515HilinkWwanApp.apk` собран и лежит рядом. `pm install`/
`adb install` на этой прошивке отключены политикой (`ro.build.type=user`), поэтому способ
установки такой же, как обсуждался для netkeeper: через USB-флешку и штатный установщик
Toolbox на голове (не просто копирование файла — установка идёт через приложение Toolbox),
либо через EngMode-инъекцию.

## Ограничения

- Всё, что делает `modem-up.sh` (адрес/маршрут на `eth1`, nat-правила DNAT) — runtime-only,
  сбрасывается ребутом. Персистентности через ребут нет и не планировалось — это ручной
  инструмент по кнопке, не демон.
- Ничего не удаляется автоматически (см. коммент в скрипте про stale DNAT-правило при смене
  шлюза модема — только предупреждение в лог).
