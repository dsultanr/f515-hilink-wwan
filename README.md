# F515 HiLink WWAN — USB-модем как интернет для головы F515

Подключаешь HiLink-модем (ZTE MF833R) в USB головы F515 — приложение поднимает его
как интернет для головы и для остальных приложений Android. Одна кнопка, без
WireGuard/туннеля.

## Установка

1. Собери `app/F515HilinkWwanApp.apk` (`app/build.sh`) или возьми готовый.
2. Установи на голову — через USB-флешку и штатный установщик Toolbox (`pm install` на
   этой прошивке отключён политикой), либо через EngMode-инъекцию. Подробнее —
   [app/README.md](app/README.md).
3. Вставь модем в USB, открой приложение, нажми **Включить**.

Готово — модем поднят как WAN, DNS фантомной TBOX-сети починен, интернет виден и
приложениям Android.

## Кнопки

- **Проверка** — диагностика, ничего не меняет
- **Включить** — поднять USB-модем как WAN и починить DNS фантомной сети
- **Интернетометр** — открыть проверку скорости в браузере
- **Форматировать SD** — выбрать съёмную SD/TF-карту (модема или флешку) из списка и
  стереть её (MBR + exFAT, с подтверждением) — необратимо

## Подробнее

Ручной запуск без приложения — прямыми командами по `adb shell`, с объяснением, что и
зачем делает каждый шаг — в [docs/manual.md](docs/manual.md).
